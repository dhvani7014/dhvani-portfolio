# Portfolio

My personal portfolio site: a place to show my experience, projects, education, technical skills and certificates in one spot.

It includes a Gemini powered assistant that answers questions about my background using the content on the site, plus a downloadable resume and direct links to my GitHub, LinkedIn and email.

**Live:** https://dhvanidave-portfolio.vercel.app/

Built with Next.js 16, React 19 and TypeScript with Framer Motion for animation. Deployed on Vercel.
